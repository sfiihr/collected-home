# Project Scope Statement

**Project Name:** Project 03: Final Project

**Project Purpose**
___
The purpose of this project is to create an interior design website that documents my journey of redesigning our home to be a collected, personalized space.  The website will provide visitors with an understanding of my design process, how my style has grown over time, and my philosophy for my personal design moving forward.

**Description**
___
This project will be a two-page personal interior design website that documents the evolution of my home and personal design style.  The website will combine photos, written content, and design inspiration to show how the spaces I've created have changed over time and the thought process behind those decisions.  The website will contain a Homepage and an About page.  The Homepage will introduce the overall project and highlight examples from my home, while the About page will provide more details about my personal journey in exploring my design style, influences, and approach to creating a collected space.  The site will use consistent visual styling and navigation across pages, and styling will be inspired by the current color palette of my home for a visually cohesive experience.  The site will be built with HTML and CSS, and will be delivered and published through GitHub.

**Desired Results**
___
The project will result in a completed and published two-page website that documents my personal interior design journey.  Success will be measured by the following outcomes:

- Create and publish two website pages: Homepage (index.html) and About (About.html)
- Use a single CSS stylesheet to create a consistent visual flow across both pages
- Include at least three images of spaces or design decisions that demonstrate my personal design style evolution
- Include at least three written content sections across the two pages describing my evolution, design process, and shift to a collected and personalized aesthetic
- Provide working navigation between each page with no broken links
- Publish the website through GitHub so it can be accessed via public URL
- Maintain all the required files within a GitHub repository, accompanied by adequate documentation for each file and each code push or change
- Complete the project aligned to the scope and submit it by the project due date, October 1, 2026 at 11:59:59 PM CST

**Exclusions**
___
The following items are outside the scope of this project:
- Completing the redesign of any space within my home that may be featured on the website.
- Documenting every room or design within my home.
- Creating more than the required two pages for the project.
- E-commerce or referral links that may be used to monetize my design projects or the products I use in them.
- Professional photography or video editing to feature my personal projects.
